# Desktop Editor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Tauri desktop app in which the operator opens a project folder, authors a layout by typing `x` markers and drawing a photo box over the template, sees a live preview, reads preflight, and generates the sheets — without the CLI and without ever editing the template in CorelDRAW.

**Architecture:** The tested TypeScript engine from the render-core plan runs *inside the webview* unchanged, except that its five Node I/O calls move behind a `FileSystem` interface (Node for the CLI and tests, Tauri's fs plugin for the app). Every editor behaviour that can be a pure function is one, lives in `app/src/lib/`, and is unit-tested in Node; React components stay thin. Marker width and baseline come from the engine's own font metrics, never from DOM measurement, so what the editor shows is what the renderer draws.

**Tech Stack:** Tauri v2, React 18, TypeScript, Vite, Tailwind, zustand, `@tauri-apps/plugin-fs`, `@tauri-apps/plugin-dialog`, the existing engine (pdf-lib, mupdf WASM, exceljs, zod), vitest + @testing-library/react.

## Prerequisites the human must install

Task 2 verifies these and stops with BLOCKED if any is missing. Do not install system packages from inside a task.

- Rust toolchain: `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh` (user-level, no sudo)
- Linux dev machine: `sudo apt install libwebkit2gtk-4.1-dev libayatana-appindicator3-dev librsvg2-dev patchelf build-essential libssl-dev` (the Ayatana package — `libappindicator3-dev` conflicts with it on current Ubuntu-based systems)
- Windows target machine: Visual Studio Build Tools with the C++ workload; WebView2 is preinstalled on Windows 10/11

## Global Constraints

- All geometry in **points, top-left origin**. The Y flip lives only in `toPdfRect`/`flipY` in `src/units.ts`. The editor's screen↔points mapping is a scale and offset, never a flip.
- **Marker width and text baseline come from the engine's font metrics** (`font.widthOfTextAtSize`, `ascentAtSize`), never from DOM or canvas measurement. The editor must not be able to disagree with the renderer.
- The template PDF is **never modified**. The editor rasterizes it for display only; output stamps the original page.
- Colour, alignment, overflow policy and cover are **field properties** set in the panel. The marker's on-screen colour is an editing colour with no output effect.
- `overflow: 'abbreviate-then-shrink'` is the default for new fields whose column name contains `name` (case-insensitive); everything else defaults to `'shrink'`.
- The engine's existing 118 tests must keep passing after Task 1 with no behavioural change.
- Sheet is 1296 x 864 pt; reference card 238.296 x 155.045 pt; reference layout is `fixtures/layout.json`.

`src/io.ts`:

```ts
/**
 * The only file-system surface the engine uses. Node implements it for the
 * CLI and tests; the desktop app implements it over Tauri's fs plugin. The
 * engine itself never imports node:fs.
 */
export interface FileSystem {
  readFile(path: string): Promise<Uint8Array>
  /** Entry names only, not paths. Rejects if the directory does not exist. */
  readDir(path: string): Promise<string[]>
  writeFile(path: string, bytes: Uint8Array): Promise<void>
  /** Recursive; succeeds if the directory already exists. */
  mkdir(path: string): Promise<void>
  exists(path: string): Promise<boolean>
}
```

`src/paths.ts`:

```ts
/** Forward-slash path helpers that work identically in Node and the webview. */
export function joinPath(...parts: string[]): string {
  const joined = parts.filter((p) => p !== '').join('/')
  return joined.replace(/\/{2,}/g, '/')
}

export function extname(p: string): string {
  const base = p.slice(p.lastIndexOf('/') + 1)
  const dot = base.lastIndexOf('.')
  return dot <= 0 ? '' : base.slice(dot).toLowerCase()
}

export function stem(p: string): string {
  const base = p.slice(p.lastIndexOf('/') + 1)
  const dot = base.lastIndexOf('.')
  return dot <= 0 ? base : base.slice(0, dot)
}

export function dirname(p: string): string {
  const i = p.lastIndexOf('/')
  if (i < 0) return '.'
  if (i === 0) return '/'
  return p.slice(0, i)
}

const ABSOLUTE = /^(\/|[A-Za-z]:[\\/])/

export function resolvePath(base: string, p: string): string {
  return ABSOLUTE.test(p) ? p : joinPath(base, p)
}
```

```ts
import { mkdir, readdir, readFile, stat, writeFile } from 'node:fs/promises'
import type { FileSystem } from './io.js'

export const nodeFs: FileSystem = {
  async readFile(path) {
    const b = await readFile(path)
    return new Uint8Array(b.buffer, b.byteOffset, b.byteLength)
  },
  readDir: (path) => readdir(path),
  writeFile: (path, bytes) => writeFile(path, bytes),
  mkdir: async (path) => { await mkdir(path, { recursive: true }) },
  async exists(path) {
    try { await stat(path); return true } catch { return false }
  },
}
```

`app/src/state/project.ts`:

```ts
import { createStore, useStore } from 'zustand'
import type { FileSystem } from '@engine/io.js'
import { parseLayout, type Layout, type Element } from '@engine/layout.js'
import { loadRows, type Row } from '@engine/data.js'
import { buildPhotoIndex, type PhotoIndex } from '@engine/photos.js'
import { joinPath, resolvePath } from '@engine/paths.js'

export type Side = 'front' | 'back'

export interface ProjectState {
  fs: FileSystem
  dir: string | null
  error: string | null
  layout: Layout | null
  templateFront: Uint8Array | null
  templateBack: Uint8Array | null
  headers: string[]
  rows: Row[]
  photos: PhotoIndex | null
  side: Side
  selectedId: string | null
  selectedRow: number
  open(dir: string): Promise<void>
  setLayout(l: Layout): void
  updateElement(id: string, patch: Partial<Element>): void
  addElement(el: Element): void
  removeElement(id: string): void
  select(id: string | null): void
  setSide(s: Side): void
  setSelectedRow(i: number): void
  save(): Promise<void>
}

export function createProjectStore(fs: FileSystem) {
  return createStore<ProjectState>((set, get) => ({
    fs, dir: null, error: null, layout: null, templateFront: null, templateBack: null,
    headers: [], rows: [], photos: null, side: 'front', selectedId: null, selectedRow: 0,

    async open(dir) {
      try {
        const layoutPath = joinPath(dir, 'layout.json')
        if (!(await fs.exists(layoutPath))) throw new Error(`No layout.json in ${dir}`)
        const layout = parseLayout(JSON.parse(new TextDecoder().decode(await fs.readFile(layoutPath))))
        const templateFront = await fs.readFile(resolvePath(dir, layout.templateFront))
        const templateBack = layout.templateBack ? await fs.readFile(resolvePath(dir, layout.templateBack)) : null
        const { headers, rows } = await loadRows(joinPath(dir, 'students.xlsx'), fs)
        const photos = await buildPhotoIndex(joinPath(dir, 'photos'), fs)
        set({ dir, layout, templateFront, templateBack, headers, rows, photos, error: null, selectedId: null, selectedRow: 0 })
      } catch (e) {
        set({ error: e instanceof Error ? e.message : String(e) })
      }
    },

    setLayout: (layout) => set({ layout }),

    updateElement(id, patch) {
      const l = get().layout; if (!l) return
      const apply = (els: Element[]) => els.map((e) => (e.id === id ? ({ ...e, ...patch } as Element) : e))
      set({ layout: { ...l, front: apply(l.front), back: apply(l.back) } })
    },

    addElement(el) {
      const l = get().layout; if (!l) return
      set({ layout: el.page === 'front' ? { ...l, front: [...l.front, el] } : { ...l, back: [...l.back, el] }, selectedId: el.id })
    },

    removeElement(id) {
      const l = get().layout; if (!l) return
      set({ layout: { ...l, front: l.front.filter((e) => e.id !== id), back: l.back.filter((e) => e.id !== id) }, selectedId: null })
    },

    select: (selectedId) => set({ selectedId }),
    setSide: (side) => set({ side, selectedId: null }),
    setSelectedRow: (selectedRow) => set({ selectedRow }),

    async save() {
      const { dir, layout } = get()
      if (!dir || !layout) return
      await fs.writeFile(joinPath(dir, 'layout.json'), new TextEncoder().encode(JSON.stringify(layout, null, 2)))
    },
  }))
}

export type ProjectStore = ReturnType<typeof createProjectStore>
let singleton: ProjectStore | null = null
export function projectStore(fs: FileSystem): ProjectStore { return (singleton ??= createProjectStore(fs)) }
export function useProject<T>(store: ProjectStore, sel: (s: ProjectState) => T): T { return useStore(store, sel) }
```

`app/src/lib/viewport.ts`:

```ts
import type { Rect } from '@engine/units.js'

/** Screen <-> points is a uniform scale plus an offset. Never a flip: the
 *  engine's top-left-origin points already match screen orientation. */
export interface Viewport { scale: number; offsetX: number; offsetY: number }

export function fitViewport(page: { w: number; h: number }, container: { w: number; h: number }, padding: number): Viewport {
  const scale = Math.min((container.w - 2 * padding) / page.w, (container.h - 2 * padding) / page.h)
  return { scale, offsetX: (container.w - page.w * scale) / 2, offsetY: (container.h - page.h * scale) / 2 }
}

export const toScreen = (vp: Viewport, p: { x: number; y: number }) => ({ x: vp.offsetX + p.x * vp.scale, y: vp.offsetY + p.y * vp.scale })
export const toPoints = (vp: Viewport, p: { x: number; y: number }) => ({ x: (p.x - vp.offsetX) / vp.scale, y: (p.y - vp.offsetY) / vp.scale })
export function rectToScreen(vp: Viewport, r: Rect): Rect {
  const o = toScreen(vp, r)
  return { x: o.x, y: o.y, w: r.w * vp.scale, h: r.h * vp.scale }
}
```

`app/src/components/Canvas.tsx` — rasterizes the current side's template once per template change at 2x the fitted scale (crisp on HiDPI), paints it to a `<canvas>`, and renders children (overlays) in an absolutely positioned layer using the same viewport:

```tsx
import { useEffect, useMemo, useRef, useState } from 'react'
import { rasterize } from '@engine/raster.js'
import type { Layout } from '@engine/layout.js'
import { fitViewport, type Viewport } from '../lib/viewport'

export function Canvas({
  template, layout, children, onClick,
}: {
  template: Uint8Array
  layout: Layout
  children: (vp: Viewport) => React.ReactNode
  onClick?: (pt: { x: number; y: number }) => void
}) {
  const wrap = useRef<HTMLDivElement>(null)
  const canvas = useRef<HTMLCanvasElement>(null)
  const [size, setSize] = useState({ w: 800, h: 600 })

  useEffect(() => {
    const el = wrap.current; if (!el) return
    const ro = new ResizeObserver(([e]) => setSize({ w: e!.contentRect.width, h: e!.contentRect.height }))
    ro.observe(el); return () => ro.disconnect()
  }, [])

  const vp = useMemo(() => fitViewport(layout.pageBox, size, 24), [layout.pageBox, size])

  useEffect(() => {
    let cancelled = false
    ;(async () => {
      const dpi = 72 * vp.scale * (window.devicePixelRatio || 1)
      const r = await rasterize(template, 0, dpi)
      if (cancelled) return
      const c = canvas.current!; c.width = r.width; c.height = r.height
      c.style.width = `${layout.pageBox.w * vp.scale}px`; c.style.height = `${layout.pageBox.h * vp.scale}px`
      c.getContext('2d')!.putImageData(new ImageData(new Uint8ClampedArray(r.rgba.buffer, r.rgba.byteOffset, r.rgba.byteLength), r.width, r.height), 0, 0)
    })()
    return () => { cancelled = true }
  }, [template, vp.scale, layout.pageBox])

  return (
    <div ref={wrap} className="relative h-full w-full overflow-hidden bg-gray-200"
      onClick={(e) => {
        if (!onClick) return
        const b = wrap.current!.getBoundingClientRect()
        onClick({ x: (e.clientX - b.left - vp.offsetX) / vp.scale, y: (e.clientY - b.top - vp.offsetY) / vp.scale })
      }}>
      <canvas ref={canvas} className="absolute shadow" style={{ left: vp.offsetX, top: vp.offsetY }} />
      <div className="absolute inset-0 pointer-events-none">{children(vp)}</div>
    </div>
  )
}
```

```ts
import type { Rect } from '@engine/units.js'

export type Handle = 'move' | 'n' | 's' | 'e' | 'w' | 'ne' | 'nw' | 'se' | 'sw'
const MIN = 4

/** Pure drag/resize maths in points. The component only supplies dx/dy. */
export function applyDrag(r: Rect, h: Handle, d: { dx: number; dy: number }, opts: { keepAspect?: boolean } = {}): Rect {
  if (h === 'move') return { ...r, x: r.x + d.dx, y: r.y + d.dy }
  let { x, y, w, hgt } = { x: r.x, y: r.y, w: r.w, hgt: r.h }
  if (h.includes('e')) w = Math.max(MIN, r.w + d.dx)
  if (h.includes('s')) hgt = Math.max(MIN, r.h + d.dy)
  if (h.includes('w')) { const nw = Math.max(MIN, r.w - d.dx); x = r.x + (r.w - nw); w = nw }
  if (h.includes('n')) { const nh = Math.max(MIN, r.h - d.dy); y = r.y + (r.h - nh); hgt = nh }
  if (opts.keepAspect) {
    const aspect = r.w / r.h
    if (h.includes('e') || h.includes('w')) { const nh = w / aspect; if (h.includes('n')) y = y + hgt - nh; hgt = nh }
    else { const nw = hgt * aspect; if (h.includes('w')) x = x + w - nw; w = nw }
  }
  return { x, y, w, h: hgt }
}
```

```ts
export function defaultOverflowFor(column: string): TextStyle['overflow'] {
  return /name/i.test(column) ? 'abbreviate-then-shrink' : 'shrink'
}

export function nextElementId(column: string, existing: { id: string }[]): string {
  const base = column.toLowerCase().replace(/[^a-z0-9]+/g, '_').replace(/^_|_$/g, '') || 'field'
  const taken = new Set(existing.map((e) => e.id))
  if (!taken.has(base)) return base
  for (let n = 2; ; n++) if (!taken.has(`${base}_${n}`)) return `${base}_${n}`
```

```ts
import type { PDFFont } from 'pdf-lib'
import type { Colour, Element } from '@engine/layout.js'
import { defaultOverflowFor, nextElementId } from './defaults'

export interface MarkerInput {
  run: string
  at: { x: number; y: number }
  page: 'front' | 'back'
  column: string
  fontId: string
  size: number
  color: Colour
  lineHeight: number
  existingIds: { id: string }[]
}

/**
 * A typed run of x becomes a text element. Its width is the engine's own
 * measurement of that many x in the chosen font and size — never a DOM
 * measurement — so the budget the operator sees is the budget the renderer
 * enforces. The x's themselves are discarded; only the count survives.
 */
export function markerToElement(m: MarkerInput, font: PDFFont): Element {
  const count = (m.run.match(/x/gi) ?? []).length
  if (count === 0) throw new Error('marker run is empty — type at least one x')
  const w = font.widthOfTextAtSize('x'.repeat(count), m.size)
  return {
    kind: 'text',
    id: nextElementId(m.column, m.existingIds),
    page: m.page,
    box: { x: m.at.x, y: m.at.y, w, h: m.lineHeight },
    bind: { column: m.column },
    style: {
      fontId: m.fontId, size: m.size, color: m.color,
      align: 'left', valign: 'top', fit: 'shrink',
      overflow: defaultOverflowFor(m.column),
      minSize: Math.max(4, Math.round(m.size * 0.66 * 4) / 4),
      lineHeight: m.lineHeight, maxLines: 1, firstLineIndent: 0,
    },
  }
}
```

```ts
 * line's indent is the horizontal offset from the leftmost line, which is
 * exactly how the reference address was measured (spec Appendix A).
 */
export function mergeMarkers(markers: TextElement[]): TextElement {
  if (markers.length === 0) throw new Error('nothing to merge')
  const column = markers[0]!.bind.column
  if (markers.some((m) => m.bind.column !== column)) throw new Error('markers must be bound to the same column to merge')
  const lines = [...markers].sort((a, b) => a.box.y - b.box.y)
  const first = lines[0]!
  const left = Math.min(...lines.map((l) => l.box.x))
  const right = Math.max(...lines.map((l) => l.box.x + l.box.w))
  const lineHeight = lines.length > 1 ? (lines[lines.length - 1]!.box.y - first.box.y) / (lines.length - 1) : first.style.lineHeight
  return {
    ...first,
    box: { x: left, y: first.box.y, w: right - left, h: lineHeight * lines.length },
    style: { ...first.style, maxLines: lines.length, firstLineIndent: first.box.x - left, lineHeight },
  }
}
```

The panel action replaces the merged markers with the single element (keeping the first's id) via `removeElement` + `addElement`.

```ts
import type { Raster } from '@engine/raster.js'
import type { Rect } from '@engine/units.js'
import type { Colour } from '@engine/layout.js'

/**
 * Mean colour of a ring `pad` pixels wide just outside `box` (box in raster
 * pixels, top-left origin). Confidence is 1 - normalised spread; a low value
 * means the background is not flat and covering will leave a visible patch.
 */
export function sampleBackground(r: Raster, box: Rect, pad: number, opts: { withConfidence?: boolean } = {}): Colour & { confidence?: number } {
  let n = 0, sr = 0, sg = 0, sb = 0
  const px: number[][] = []
  const x0 = Math.max(0, Math.floor(box.x - pad)), y0 = Math.max(0, Math.floor(box.y - pad))
  const x1 = Math.min(r.width, Math.ceil(box.x + box.w + pad)), y1 = Math.min(r.height, Math.ceil(box.y + box.h + pad))
  for (let y = y0; y < y1; y++) for (let x = x0; x < x1; x++) {
    const inside = x >= box.x && x < box.x + box.w && y >= box.y && y < box.y + box.h
    if (inside) continue
    const i = (y * r.width + x) * 4
    if ((r.rgba[i + 3] ?? 0) === 0) { px.push([255, 255, 255]); sr += 255; sg += 255; sb += 255; n++; continue }
    const p = [r.rgba[i] ?? 0, r.rgba[i + 1] ?? 0, r.rgba[i + 2] ?? 0]
    px.push(p); sr += p[0]!; sg += p[1]!; sb += p[2]!; n++
  }
  if (n === 0) return { space: 'rgb', r: 1, g: 1, b: 1, confidence: 0 }
  const mean = [sr / n, sg / n, sb / n]
  const out: Colour & { confidence?: number } = { space: 'rgb', r: mean[0]! / 255, g: mean[1]! / 255, b: mean[2]! / 255 }
  if (opts.withConfidence) {
    const spread = px.reduce((acc, p) => acc + Math.abs(p[0]! - mean[0]!) + Math.abs(p[1]! - mean[1]!) + Math.abs(p[2]! - mean[2]!), 0) / (n * 3 * 255)
    out.confidence = Math.max(0, 1 - spread * 4)
  }
  return out
}
```

Note the pad converts from points to raster pixels: the Properties panel samples from the canvas's raster with `box` scaled by `raster.dpi / 72`.
